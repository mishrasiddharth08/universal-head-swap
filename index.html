🔁

Auto model switching

Select the checkpoint in Forge's dropdown — Klein or Qwen 2.1 — and the extension switches its reference plumbing, LoRA matching and prompt formatting automatically. No manual mode toggle.

🎭

BFS head swap

Use the original picture as the body/scene reference and a selected headshot as the identity reference, powered by Alissonerdx's BFS (Best Face Swap) LoRAs.

🛡️

Protected head edit

Dedicated sampling canvas for the head region, composited back into the untouched original. Optional custom mask, feathering and crop padding.

🧼

Whole-body cleanup

Removal policies for tattoos, henna, body ink, piercings, earrings, jewelry, forehead marks and cross symbols — resolved in one deterministic prompt plan.

🔍

Face-match auditing

Local CPU comparison against the selected headshot with SFace embeddings, bounded background worker, review statuses and JSON export.

📐

Proportions & sharpness

Preserve canvas aspect ratio, guide head/body scale, measured head-height correction with isotropic transform, and detail-matched sharpening.

⚡

Any VRAM, any quant

Project-Invisible memory policy: device-aware probing (never assumes GPU 0), bounded reference budgets, OOM retry, RAM-backed encode cache, all modern quantization formats via Forge's own loaders.

🧩

Zero core edits

Hook-only Forge integration via a scoped, removable bridge. Delete the extension folder and Forge is 100% stock. Every hook forwards *args/**kwargs.

How auto-switching works

FLUX.2 Klein 4B / 9BQwen Image Edit 2.1
Detectiondynamic_args.klein + hidden_size (3072→4B, 4096→9B)dynamic_args.edit + Qwen text engine
Reference pathVAE latents in model.ref_latentsPixel-space start image + vision-token prompts
Prompt numberingPicture 1 = target, Picture 2 = headshotAuto-remapped (Picture 0 = target, prepended by Forge)
AdaptersKlein-family BFS LoRAs, size-matchedQwen-family BFS + character LoRAs, family-locked
Latent sharpeningSupportedSkipped (pixel-space path)

Everything else — removal policies, protected editing, face audit, presets, fine-grid cleanup, quality gates — is identical in both modes.

Install

cd <forge>/extensions
git clone https://github.com/YOUR-USERNAME/universal-head-swap
  1. Load a Klein 4B/9B or Qwen Image Edit 2.1 checkpoint and its matching BFS LoRA.
  2. Open img2img, upload the body/scene target, enable Universal Head Swap in the accordion.
  3. Upload 1–20 sharp identity headshots.
  4. Leave the adapter on Auto (match model), denoising at the BFS start value (1.0), pick a fixed seed, click Check setup.
  5. Generate with Forge's normal Generate button and inspect Show last generation report.

Optional face analysis: place face_landmarker.task at scripts/models/ and install MediaPipe in Forge's own Python environment — see the full README for pinned URLs and hashes. No automatic downloads ever run.

Requirements

  • Forge Neo (sd-webui-forge-classic, neo branch) with Klein or Qwen-Image-Edit support
  • Checkpoint + matching BFS face/head-swap LoRA (Klein LoRAs do not interchange with Qwen — the extension enforces this)
  • Works on NVIDIA (CUDA), AMD (ROCm) and CPU; DirectML/Vulkan not implemented. FP8 acceleration probes skipped on ROCm; portable storage fallbacks used.
